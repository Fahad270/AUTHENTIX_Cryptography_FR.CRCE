# Objective

After completing this experiment, the learner should be able to:

1. Explain why passwords must be stored as salted, slow password hashes rather
   than plaintext.
2. Distinguish brute-force, credential-stuffing, and password-spraying
   strategies.
3. Run each simulated attack against AUTHENTIX's fictional seeded accounts.
4. Interpret successful and failed authentication events in the dashboard and
   attack history.
5. Explain why a small key space and password reuse make authentication systems
   vulnerable.
6. Identify practical defenses, including rate limiting, lockout, MFA,
   CAPTCHA or adaptive challenges, detection, and incident response.
