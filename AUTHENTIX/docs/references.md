# References

1. OWASP Foundation. [Password Storage Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html).
   Guidance on password hashing, salting, work factors, and secure storage.
2. OWASP Foundation. [Authentication Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Authentication_Cheat_Sheet.html).
   Guidance on authentication controls, throttling, MFA, and monitoring.
3. OWASP Foundation. [Credential Stuffing Prevention Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Credential_Stuffing_Prevention_Cheat_Sheet.html).
   Background on credential stuffing and defensive measures.
4. NIST. [SP 800-63B: Digital Identity Guidelines — Authentication and Lifecycle Management](https://pages.nist.gov/800-63-4/sp800-63b.html).
   Recommendations for memorized secrets and verifiers.
5. Provos, N. and Mazieres, D. [bcrypt: A Cost-Adaptive Password-Hashing Scheme](https://www.usenix.org/legacy/events/usenix99/provos.html).
   Original description of the bcrypt password-hashing scheme.
6. MITRE ATT&CK. [Valid Accounts (T1078)](https://attack.mitre.org/techniques/T1078/).
   Adversary use of legitimate account credentials.
